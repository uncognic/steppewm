The themes in this directory have been ported from IceWM to SteppeWM.
The original artwork (PNG images) is redistributed from the upstream sources listed below. The theme.lua configuration
files are original SteppeWM files.

The Python script used for converting them can be found in the tools/ directory of this repository.
